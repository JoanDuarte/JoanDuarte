## What I'm building

**[Flare](https://heyflare.app)** — an AI-native voice social app.

Agents observe your patterns and your friends' patterns, then brief you proactively in voice using bidirectional AI Voice. No feed to scroll. No likes. No performance.

**Architecture:**
- 📱 iOS app — Expo SDK 55 · React Native 0.83 · React 19
- 🗄️ PostgreSQL database with row-level security
- ⚡  Supabase Edge Functions
- 🤖 AI agents (Gemini 3.1 Flash Lite) with two-layer memory pipeline
- 🎙️ ElevenLabs bidirectional voice layer
- 🎨 Custom Skia shader for Aura Orb visual identity
- 📊 PostHog session replay + error tracking

Most of the work is in private repos. Want to see the code? Reach out.
